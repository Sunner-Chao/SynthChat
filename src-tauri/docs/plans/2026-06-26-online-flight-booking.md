# 网上订购机票实施计划

> **For 小孙:** Use this plan to book a flight ticket online step-by-step.

**Goal:** 顺利完成网上机票订购，获取确认订单和电子客票。

**Architecture:** 采用主流在线旅行平台（携程/飞猪/去哪儿/航司官网）完成搜索、比价、下单、支付全流程。

**Tech Stack:** 浏览器 + 手机号 + 支付工具（支付宝/微信/银行卡）

---

## 任务拆解

### Task 1: 准备工作环境（2分钟）

**Objective:** 确保设备和账号准备就绪

**工具清单:**
- 电脑或手机（已联网）
- 浏览器（Chrome/Safari/Edge）或旅行App
- 手机号（用于接收验证码）
- 支付工具（支付宝/微信/银行卡）

**Step 1: 确认设备状态**

```
检查项：
□ 设备电量充足
□ 网络连接正常
□ 浏览器已更新到最新版本
```

**Step 2: 登录或注册账号**

```
平台推荐（任选一个）：
- 携程：https://flights.ctrip.com
- 飞猪：https://www.fliggy.com
- 去哪儿：https://flight.qunar.com
- 航司官网（如国航、东航、南航）

验证：成功登录后显示用户名/头像
```

**Step 3: 准备支付工具**

```
验证：支付宝/微信支付功能正常，余额或银行卡可用
```

---

### Task 2: 搜索航班（3分钟）

**Objective:** 查询目标日期和路线的航班信息

**Step 1: 进入机票搜索页面**

```
操作：
1. 打开浏览器，输入平台网址
2. 点击"机票"或"国内机票"选项卡
3. 验证：搜索框显示"单程/往返"选项
```

**Step 2: 填写行程信息**

```
填写内容：
□ 出发城市：_______________
□ 到达城市：_______________  
□ 出发日期：_______________
□ 返程日期（如往返）：_______________
□ 乘客人数：_______________
□ 舱位：经济舱/商务舱

验证：系统显示"查询中"或加载动画
```

**Step 3: 等待搜索结果**

```
预期结果：
- 页面显示航班列表
- 包含：航班号、起飞时间、到达时间、价格、航空公司

验证：至少显示3个以上航班选项
```

---

### Task 3: 筛选和比价（3分钟）

**Objective:** 选择最适合的航班

**Step 1: 设置筛选条件**

```
可用筛选项：
□ 起飞时间段（早/中/晚）
□ 航空公司偏好
□ 是否直飞/中转
□ 价格区间

验证：筛选后航班数量减少但更精准
```

**Step 2: 对比航班信息**

```
比较维度：
- 价格：最低价 vs 舒适度
- 时间：出发/到达是否合适
- 航程：直飞 vs 中转（中转耗时）
- 航司：服务评价、行李额度

验证：选定1-2个备选航班
```

**Step 3: 查看详细信息**

```
点击航班展开详情：
□ 退改签政策
□ 行李额度
□ 机建燃油费
□ 总价（含税）

验证：总价清晰，退改规则明确
```

---

### Task 4: 填写乘机人信息（2分钟）

**Objective:** 准确录入所有乘客信息

**Step 1: 添加乘机人**

```
信息填写（每位乘客）：
□ 姓名：_______________（与证件一致）
□ 证件类型：身份证/护照/港澳通行证
□ 证件号码：_______________
□ 手机号：_______________

验证：系统校验通过，无红色提示
```

**Step 2: 核对信息**

```
检查清单：
□ 姓名无错别字
□ 证件号码正确
□ 联系方式有效
□ 特殊需求（如轮椅、婴儿）已备注

验证：信息显示完整，可编辑修改
```

---

### Task 5: 确认订单并支付（3分钟）

**Objective:** 完成下单和支付

**Step 1: 确认订单信息**

```
最终确认：
□ 行程：___月___日 ___:___ → ___:___
□ 乘客：_______________
□ 总价：¥_______________
□ 联系方式：_______________

验证：订单详情页显示所有信息
```

**Step 2: 选择支付方式**

```
支付选项（任选）：
□ 支付宝
□ 微信支付
□ 银行卡
□ 平台余额

验证：跳转到支付页面
```

**Step 3: 完成支付**

```
操作：
1. 输入支付密码/验证码
2. 等待支付结果
3. 验证：页面显示"支付成功"
```

---

### Task 6: 获取确认信息（2分钟）

**Objective:** 保存订单凭证

**Step 1: 查看订单详情**

```
确认信息：
□ 订单号：_______________
□ 出票状态：已出票
□ 电子客票号：_______________
□ 行程单信息

验证：订单状态显示"已完成"
```

**Step 2: 保存凭证**

```
保存方式（任选）：
□ 截图保存到手机相册
□ 转发确认短信到微信收藏
□ 下载行程单PDF（如需要报销）

验证：凭证可随时查看
```

**Step 3: 检查邮件/短信**

```
验证：
□ 收到平台确认短信
□ 收到平台确认邮件（如有）
□ 航司可能单独发送值机提醒

验证：至少收到1条确认通知
```

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| 搜不到航班 | 检查城市名称、日期是否正确 |
| 价格突然变化 | 可能是舱位余票紧张，刷新重试 |
| 支付失败 | 检查余额/网络，或更换支付方式 |
| 没收到确认 | 检查短信拦截箱，或联系客服 |

```
- 不要点击短信中的不明链接
- 核对航班信息再支付
- 保护好个人证件信息
```
